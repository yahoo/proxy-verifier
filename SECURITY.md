# Security Policy

Thank you for taking the time to make us aware of vulnerabilities in Proxy Verifier.

## Reporting a Vulnerability

Please submit security vulnerablities via GitHub's security reporting mechanism enabled with this repository. 
Thus to report a vulnerability, please do the following:

- Navigate to the main page of the repository: https://github.com/yahoo/proxy-verifier
- Click on the "Security and quality" tab along the top tabs listed for the repository.
- Click on the "Report a vulnerability" button.

For general information about GitHub's security reporting feature, please see:
https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/privately-reporting-a-security-vulnerability
